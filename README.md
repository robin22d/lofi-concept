# LOFI website concept

A concept redesign of [lofi.com](https://www.lofi.com) for LOFI Design Ltd, Cardigan.

This is a demo. The cart works in the browser so the flow can be tried, but checkout, payments, forms and email signup aren't connected to anything. Every page is set to noindex so it won't show up in search.

Open `index.html` to start.
